## 2. Manual Payout — How to Send Amount Easy Advanced? — Pin-to-Pin 📱

### Option A: PhonePe App Manual — Easy, 10 Sec per Payout — Best for Starting (0-100 payouts/week)

**Steps Pin-to-Pin:**

1. Admin Panel `/admin` → Referral Payouts → Pending list → Sort by amount high
2. Click **Copy UPI** for LAK42 → UPI `98480xxxxx@ybl` copied
3. Click **Copy Amount** → `250` copied
4. Open PhonePe app → UPI ID / Phone Number → Paste UPI → Amount paste 250 → Note "TSAP Referral LAK42 — 5 pays" → Send
5. PhonePe success → Come back to Admin Panel → Click **Mark as Paid** → Enter Transaction ID (optional) → Save → Referrer gets notification "🎉 Meeku ₹250 payout ayyindi PhonePe lo! Transaction ID: XXX — Thank you!"
6. Referrer dashboard update: Pending ₹250 → Paid, Wallet history: "2025-09-10 — ₹250 Paid via PhonePe — TXN XXX"

**Time:** 10 sec per payout — 10 payouts = 100 sec = 1.5 min — easy for 0-100 payouts/week — manual best!

**Smart Features for Easy Manual:**

- **Copy Buttons:** 1-click copy UPI, Amount, Note — no typing
- **PhonePe Deep Link:** Click "Open PhonePe" → `phonepe://pay?pa=98480xxxxx@ybl&pn=Lakshmi&am=250&tn=TSAP Referral LAK42` → PhonePe app auto open with UPI + Amount + Note filled — just Send click — 5 sec!
- **GooglePay Deep Link:** `tez://upi/pay?pa=...&am=...&tn=...`
- **WhatsApp Message Auto:** After Mark as Paid → Auto WhatsApp/Telegram message to referrer "Meeku ₹250 payout ayyindi — check PhonePe — TXN XXX — Thank you for 5 refers!"
- **Payout History:** Every payout log — date, amount, method, TXN ID, admin who paid — audit

## 3. Payout Details Collection — First Ye List — Easy Advanced — Best

**What to Collect First? — Minimum for Easy Manual:**

1. **UPI ID (Must):** `98480xxxxx@ybl` or phone number `98480xxxxx` — 1 field — easy — 10 sec — chalu for manual!
2. **Bank Optional (Backup):** Account No + IFSC + Name — 3 fields — optional — UPI fail ayithe backup — but 99% UPI works — so optional

**Why Not Collect Too Much First?**
- Too many fields → form long → referrers drop — ladies, students, village brokers ki kastam — typing ekkuva — form abandon
- So first: UPI ID only must — bank optional — easy — advanced best!

**Validation — Smart:**

- UPI ID: Must contain @ OR 10 digits — instant check — "UPI ID lo @ undali — e.g. 98480xxxxx@ybl" OR "Phone number 10 digits"
- Bank IFSC: If entered, must be 11 chars + 4 letters + 0 + 6 alphanumeric — auto validate + bank name auto from IFSC API
- Duplicate UPI check — same UPI already used by another referrer? → Warning — maybe fraud

**List Management — Advanced Best — Easy for Admin:**

- **Admin Panel `/admin/referrals` Tab:**

  - Export: CSV for record, Excel for accounting

- **Payout Rules — Smart:**
